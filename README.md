# DYNAMIXEL ID Studio

Public app downloads for Windows, macOS (Apple Silicon and Intel), and Linux. No Python installation required.

## Download

Open [Releases](https://github.com/RINC-ROBOTISAmerica/DYNAMIXEL-ID-Studio-Releases/releases), choose the archive for your computer, extract it completely, and run the included app. Do not download the automatically generated Source code archives: this repository contains release documentation only.

Version 0.6.0 and later checks these public releases for updates without a token or sign-in. The source code and development history are maintained in a separate private repository.

## Getting started

Connect and power your robot, select the port and baud rate, then scan. Use LED identification or Move-2-ID, choose your starting ID and threshold, and save all IDs. The app includes offline Help and definitions (F1).

This is an early-access custom tool, not an official ROBOTIS DYNAMIXEL Wizard application. See each release for model coverage and validation limits. Applications are unsigned/not notarized. ROBOTIS/DYNAMIXEL marks retain their respective owners' rights; included third-party notices apply.
